# oceanshell

A nautical-themed terminal prompt with ocean waves and sea colors. Set sail in your terminal.

## Install

```bash
npm install -g oceanshell
```

## Usage

```bash
# Show the welcome banner
oceanshell banner

# Get the PS1 string for your shell
oceanshell ps1

# Print install instructions
oceanshell install
```

## Add to your shell

Add this line to your `.bashrc` or `.zshrc`:

```bash
eval "$(npx oceanshell ps1)"
```
